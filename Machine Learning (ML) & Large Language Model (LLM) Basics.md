## 1. Classical Machine Learning Fundamentals
Machine Learning is the practice of training algorithms on data so they can learn patterns and make predictions without being explicitly programmed. [1, 2, 3, 4] 

* 
* Supervised Learning: Training a model using labeled data (input data paired with the correct output answer).
* Regression: Predicts a continuous, numerical value (e.g., predicting house price, temperature, or sales revenue).
   * Classification: Predicts a discrete category or class label (e.g., classifying an email as Spam/Not Spam or an image as Cat/Dog). [5, 6, 7, 8, 9] 
* Unsupervised Learning: Training a model on unlabeled data to find hidden structures or patterns.
* Clustering: Grouping similar data points together based on shared features (e.g., customer segmentation for marketing). [10, 11, 12, 13, 14] 
* Key Model Evaluation Metrics:
* Regression Metrics: Root Mean Squared Error (RMSE) or Mean Absolute Error (MAE). Lower values mean higher accuracy.
   * Classification Metrics: Accuracy, Precision, Recall, and F₁-Score. [15] 
* 

------------------------------
## 2. Deep Learning Basics
Deep learning is a subset of ML based on artificial neural networks inspired by the human brain. [16, 17, 18] 

* 
* Neural Networks: Consist of an input layer, one or more hidden layers (where features are extracted), and an output layer.
* Deep Learning Workloads: Primarily powers advanced cognitive tasks like complex Computer Vision (facial recognition, object tracking) and Natural Language Processing (NLP). [19, 20] 
* 

------------------------------
## 3. Large Language Models (LLMs) & Foundation Models
LLMs are advanced deep learning models trained on massive datasets to understand and generate human-like text. [21, 22, 23] 

* 
* Foundation Models: Huge, generalized models (like GPT-4) trained on broad data that can be adapted to a wide range of downstream tasks (text generation, translation, coding). [24] 
* The Transformer Architecture: The underlying breakthrough structure powering LLMs. It uses a self-attention mechanism to process all words in a sentence simultaneously, understanding the context and relationships between words regardless of their distance from each other. [25, 26, 27] 
* Tokenization: The process of breaking down text into smaller units called tokens (which can be whole words, syllables, or characters) before the model processes them. [28, 29, 30] 
* 

------------------------------
## 4. Customizing and Improving LLMs
The exam heavily tests how to optimize an LLM for specific business use cases.

* 
* Prompt Engineering: Crafting and refining the input text (prompt) to guide the LLM to a better output. This includes techniques like Few-Shot Prompting (providing a few examples of the desired output within the prompt). [31, 32, 33] 
* Retrieval-Augmented Generation (RAG): Optimizing LLM outputs by querying an external, authoritative knowledge base (like an internal company database) before generating a response.
* Why it matters: Prevents hallucinations (generating false information) and ensures data is up-to-date without retraining the model.
* Fine-Tuning: A supervised learning process where you take an existing foundation model and train it further on a smaller, specialized dataset to change its behavior, tone, or domain expertise.
* 

------------------------------
## 5. Responsible AI in LLMs

* 
* Overreliance: The risk of human users trusting AI outputs blindly without verifying facts, leading to critical errors.
* Hallucination: When a generative AI model confidently states factually incorrect, fabricated, or nonsensical information as true. [34, 35, 36]
