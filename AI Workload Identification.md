For the Microsoft AI-901 exam, "AI Workload Identification" requires mapping real-world business scenarios to the correct AI capability. The exam tests your ability to spot keywords in a scenario and choose the right workload. [1, 2, 3, 4, 5] 
## 1. Generative & Agentic AI

* 
* Core Idea: Creating new content or building multi-step, autonomous workflows.
* Exam Keywords: Co-pilot, chat application, multi-step workflow, autonomous task execution, code generation.
* Scenario: Deploying an autonomous AI agent via [Microsoft Foundry](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-901) that handles customer refunds by checking a database, updating a ticket, and drafting an email. [6, 7] 
* 

## 2. Text Analysis (NLP)

* 
* Core Idea: Processing, analyzing, and extracting meaning from unstructured written text. [8] 
* Key Techniques to Know:
* Sentiment Analysis: Classifying text as positive, negative, or neutral (e.g., analyzing social media reviews).
   * Entity Detection: Identifying specific names, locations, brands, or dates within a document.
   * Keyword/Key Phrase Extraction: Pinpointing the main talking points or tags in a long article.
   * Summarization: Generating a brief abstract from long blocks of text. [6, 8, 9, 10, 11] 
* 

## 3. Speech

* 
* Core Idea: Converting spoken language into data or vice versa. [6, 9] 
* Key Techniques to Know:
* Speech Recognition (Speech-to-Text): Translating spoken audio into a written transcript (e.g., live captions).
   * Speech Synthesis (Text-to-Speech): Converting typed text into audible, natural-sounding voice output. [9, 10, 12, 13] 
* 

## 4. Computer Vision

* 
* Core Idea: Extracting meaning, tags, or structural insights from visual media. [10] 
* Key Techniques to Know:
* Image Analysis / Object Detection: Identifying specific items, bounding boxes, or categories within a picture (e.g., checking warehouse inventory).
   * Image/Video Generation: Using multimodal foundation models to generate brand-new graphics, art, or video clips from text prompts. [6, 13, 14, 15, 16] 
* 

## 5. Information Extraction

* 
* Core Idea: Turning unstructured, multi-format documentation directly into structured database records.
* Exam Tool Connection: Realized through Azure Content Understanding.
* Scenario: Ingesting a folder of receipts, voicemail audio files, and video recordings to automatically spit out a standardized JSON schema containing names, dates, amounts, and actions. [6, 7, 12] 
* 

## 6. Classical Machine Learning (Quick Check)

* 
* Regression / Prediction: Estimating a continuous numerical future value (e.g., forecasting house prices or next month's energy demand).
* Classification: Sorting items into discrete, predefined buckets (e.g., checking if an email is "Spam" or "Not Spam").
* Anomaly Detection: Flagging rare, unusual data points that deviate from normal patterns (e.g., credit card fraud detection or network security drops). [3, 14, 17, 18] 
*
